# Dashboard data package

The files in `data/` are curated aggregate outputs for Power BI portable-import mode. They contain no raw order, customer, seller, product, payment, review, or geolocation records.

They are generated by:

1. `sql/17_create_dashboard_exports.sql`
2. `sql/18_dashboard_reconciliation.sql`
3. `sql/19_export_dashboard_csvs.sql` through `psql`

| File | Data rows | Grain |
|---|---:|---|
| `executive_kpis.csv` | 2 | Matched comparison period |
| `monthly_trend.csv` | 20 | Stable purchase month |
| `category_state.csv` | 104 | Ranked category × customer state |
| `seller.csv` | 93 | Ranked seller |
| `route.csv` | 50 | Ranked seller-state → customer-state route |
| `delay_band.csv` | 5 | Delivery-timing band |
| `growth_contributor.csv` | 101 | Category or customer-state contributor |

Use PostgreSQL views as the preferred Power BI source. CSV mode is a portable fallback and recruiter-review aid.
